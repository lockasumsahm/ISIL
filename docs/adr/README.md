# ISIL Architecture Decision Records

Every durable architectural decision receives an ADR.

Required fields:

- Context
- Decision
- Alternatives considered
- Security impact
- Operational impact
- Rollout strategy
- Reversibility
- Verification
- Status

Initial decision areas:
